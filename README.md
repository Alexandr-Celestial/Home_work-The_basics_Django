# Домашняя работа 21ю2

## Описание

Это простое веб-приложение, созданное в рамках учебного задания. Приложение реализует обработку GET-запросов и рендерит HTML-шаблоны для следующих страниц:

- **Главная**
- **Каталог**
- **Категория**
- **Контакты**

Стилизация страниц выполнена с использованием Bootstrap.

---

## Работа с Git и GitHub

- Домашнее задание сдано через **pull request** из ветки домашней работы в ветку `develop`.
- В коммиты не добавлены игнорируемые файлы.
- В корне проекта создан файл **.gitignore**, в котором учтены:
  - `.idea`
  - `venv`
  - `__pycache__`
  - `env`
  - Базы данных sqlite (например, `*.sqlite3`, `*.db`)

---

## Сборка страниц по макету

- Все страницы собраны по предоставленному макету.
- Используются стили Bootstrap для единообразия и адаптивности.

---

## Веб-приложение

- Приложение обрабатывает GET-запросы и рендерит соответствующие HTML-шаблоны.
- Код HTML-страниц считывается из файлов с помощью функции `open()`.
- Стили Bootstrap подключены корректно, отображение страниц соответствует макету.

## Запуск проекта

1. Клонируйте репозиторий:
git clone <ссылка_на_репозиторий>
cd <название_проекта>

text

2. Создайте и активируйте виртуальное окружение:
python -m venv venv
source venv/bin/activate # для Linux/Mac
venv\Scripts\activate # для Windows

text

3. Установите зависимости (если есть файл requirements.txt):
pip install -r requirements.txt

text

4. Запустите приложение:
python app.py

text

5. Откройте в браузере [http://localhost:5000](http://localhost:5000) (или другой указанный порт).
